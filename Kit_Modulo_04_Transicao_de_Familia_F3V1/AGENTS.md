# Orientações para agentes

Leia LEIA_PRIMEIRO.md, HANDOFF.md eGATEKEEPING.md antes de atuar. OST está pausada. Não introduzir áudio, IA, upload, telemetria ou migraçãoOST.

Preservar originais, aprovações vinculadas a hashes e separação privado/público. Não executar scripts dos inputs, nem instalar dependências a partir de package.json legado. Não mudar stack, limites ou escopo silenciosamente.

Não converter recuperação em “migração F3” por mudança de rótulo. Não promover candidato sem build oficial, regressões de domínio, perfis e revisão de publicação. Não fabricar lockfile, assinatura, teste remoto ou certificaçãoWCAG.

Atualizar somente versões atuais de cada documento. Reexecutar testes após mudanças no núcleo ou UI e reconstruir a prévia a partir das fontes; não editar HTML gerado manualmente. Não remover testes para obter verde.
