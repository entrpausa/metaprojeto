Kits e módulos do Ateliê Metaprojeto, com desenvolvimento da Família 3 para uso local e web, migração de legados, componentes compartilhados, testes e documentação rastreável.

## Estado atual

O Kit 04 é candidato, não um kit F3 homologado. Reconhece estruturas legadas e recupera fontes privadamente, mas ainda não transforma os módulos em F3. OST permanece pausada.

A pasta original importada foi preservada. A evolução acontece na branch f3/kit-04-consolidacao; não integrar o PR nº 1 à main antes da revisão.

## Verificação automática inicial

O workflow Kit 04 verifica o pacote original e repete testes nativos em Node 26. Não instala dependências, produz build oficial, publica ou faz merge. Um resultado verde não equivale a homologação F3.

Consulte o resultado real na aba Actions: configuração não comprova execução. Esta rodada preparou o workflow; sua primeira execução remota permanece pendente.

Os HTMLs originais dos pilotos não estão incluídos. Não enviar entrevistas, backups, credenciais ou dados privados para completar testes.
